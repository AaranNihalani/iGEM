A per-protease binary classifier (\texttt{predict.py}) ranks candidate 8-mer P4--P4'
substrate peptides for each of the six panel proteases by predicted cleavage probability
and selectivity over the remaining five competitors. Two model types are trained:
logistic regression (L2) on 64-dimensional VHSE8 physicochemical features (primary,
interpretable), and LightGBM on the same VHSE8 features (comparison). Candidate
generation enumerates $3^8 = 6{,}561$ sequences from the top-3 PSSM-preferred amino
acids at each position. The tool is the primary candidate for the iGEM Best Software
Tool award.

\section{Task 7: ML Substrate Peptide Prediction Tool}
% ============================================================

\subsection{Data Pipeline}

Positive training examples are confirmed P4--P4' cleavage windows extracted from the MEROPS
bulk substrate file (\texttt{Substrate\_search.txt}, 108\,k rows), shared with the Task~6
cross-reactivity pipeline. Negative examples are constructed at a 1:3 positive-to-negative
ratio from two sources: (i)~composition-shuffled positives (two random permutations of each
positive sequence, preserving amino acid composition) and (ii)~random 8-mers sampled from
Swiss-Prot background amino acid frequencies. Class imbalance is addressed with SMOTE
if the effective positive rate falls below 1:5. The Fecal panel member
(dominated by trypsin-1, $n > 18{,}000$) is capped at 5\,000 positives to avoid
training-set dominance.

tiers (high: $\geq 200$ positives; medium: 50--199; low: $<50$).

\subsection{Feature Representation}

The primary representation is the VHSE8 physicochemical encoding (Mei et al.\ 2005): each
position in the P4--P4' window is described by eight descriptors, yielding a 64-dimensional
vector. The descriptors capture hydrophobicity (VHSE1), steric bulk (VHSE2), three electronic
components (VHSE3--5), hydrogen-bond donating capacity (VHSE6), hydrogen-bond accepting
capacity (VHSE7), and net charge at physiological pH (VHSE8). Glycine is the zero
reference for all descriptors. This encoding maps directly to the subsite specificity
framework used in protease biochemistry and is fully interpretable via the logistic
regression coefficient matrix.

Both the logistic regression and LightGBM classifiers were trained on the 64-dimensional
VHSE8 feature vector exclusively; this is the feature set used for all results in this
report. An optional ESM2 extension is implemented in the codebase
(\texttt{esm2\_t6\_8M\_UR50D}, 320-dimensional mean-pooled embeddings; HuggingFace
\texttt{transformers}): passing \texttt{--esm2} to \texttt{train\_models.py} would
concatenate ESM2 embeddings with VHSE8 features (384-dimensional combined vector) for
the LightGBM model only. ESM2 was not available in the current training environment and
was not used.

\subsection{Classifiers and Cross-Validation}

Per-protease binary classifiers are trained independently. The primary model is
\textbf{logistic regression} (L2, $C = 1.0$, \texttt{class\_weight='balanced'},
LBFGS solver, 2000 iterations) applied to VHSE8 features. A LightGBM comparison model
(500 estimators, $\eta = 0.05$, 31 leaves; requires \texttt{lightgbm}) is implemented
as an available extension.

\textbf{Model choice rationale.} Logistic regression on VHSE8 features is the appropriate
primary model for these dataset sizes (96--341 positives for MMP and NE). Protease
specificity is well-described by position-specific additive effects: the S1, S2, and S1'
subsites impose independent amino acid preferences that sum in log-odds space, which is
exactly the assumption of an L2-regularised linear classifier (and of the PSSM in
Task~6). More complex models (gradient-boosted trees, neural networks) would need
substantially larger training sets to learn position--position interaction terms
reliably; at $n < 400$ positives, any improvement over LR in cross-validation is likely
variance rather than bias reduction. The Fecal case (5,000 positives, AUROC 0.938)
confirms that the VHSE8 + LR architecture saturates performance when data are abundant,
indicating that the performance ceiling for the smaller proteases is set by data quantity,
not model capacity. The empirical comparison in Table~\ref{tab:cv_results} confirms this:
LR and LightGBM differ by at most $\Delta\text{AUROC} = 0.013$ across all proteases with
sufficient data, well within cross-validation variance. At MMP14 ($n = 129$), LightGBM
is worse than LR (AUROC 0.726 vs 0.752), the expected signature of tree-model overfitting
on a small dataset. LR is therefore the operationally correct primary model.

Performance is estimated by stratified 5-fold cross-validation. Table~\ref{tab:cv_results}
reports mean AUROC, Matthews correlation coefficient (MCC), precision-recall AUC (PR-AUC),
and Brier score. FAP is omitted from AUROC and has a degenerate CV due to $n = 2$ positives.

\subsection{Selectivity Scoring}

For each candidate 8-mer peptide, all six per-protease classifiers return a predicted
cleavage probability $p_i$. The selectivity index for target protease $i$ is:
\[
  S_i = \frac{p_i}{\max_{j \neq i}\, p_j}
\]
The joint ranking score combining predicted cleavage probability with selectivity is:
\[
  \text{score} = p_i \cdot \log(S_i + 1)
\]
The logarithm softens extreme selectivity values; the additive 1 avoids $\log 0$ when
competing classifiers assign high probability. Candidates are ranked by joint score.
Table~\ref{tab:top_candidates} lists the top-ranked candidate per protease.

\subsection{CLI Usage}

\begin{lstlisting}[language=bash]
# Rank top 10 candidate motifs for MMP14
python predict.py --protease MMP14 --top-k 10

# Scan a FASTA sequence for NE cleavage sites
python predict.py --protease NE --scan SEQUENCE.fasta --top-k 5

# Save predictions to CSV
python predict.py --protease MMP-9 --top-k 20 --save
\end{lstlisting}

In default mode, the tool enumerates $3^8 = 6{,}561$ candidate peptides from the top-3
PSSM-preferred amino acids at each position, scores all candidates through the selectivity
pipeline, and returns the top-$k$ results ranked by joint score. In scan mode, the tool
slides an 8-mer window across the input FASTA sequence and returns the top-$k$ windows
with their sequence coordinates.

\subsection{Validation: SGRSENIR Analysis}

The known sensor peptide for MMP14 is SGRSENIRTA (8-mer core: \texttt{SGRSENIR}),
derived from the proMMP-2 autolytic cleavage site. It has been validated as an MMP14
substrate with $k_\text{cat}/K_M = 5.5 \times 10^4\ \text{M}^{-1}\text{s}^{-1}$
(Ohuchi et al.\ 1997), which underpins the Task~2 LOD calculation ($K_d = 7.0\ \text{nM}$,
LOD $\approx 7\ \text{pM}$ at 0.1\% noise floor). Direct scoring via the ML selectivity
pipeline returns:

\begin{lstlisting}
SGRSENIR: p_cleave = 0.098, selectivity = 0.143, joint score = 0.013
Per-protease probabilities:
  MMP14 = 0.098,  MMP-8 = 0.024,  MMP-9 = 0.260
  NE    = 0.065,  Fecal = 0.005,  FAP   = 0.685
\end{lstlisting}

\texttt{SGRSENIR} ranks outside the top 6{,}000 ML candidates for MMP14. Its low
predicted MMP14 cleavage probability (0.098) and negative selectivity index ($S < 1$)
arise from two independent sources.

First, SGRSENIR is not among the natural ECM substrates represented in MEROPS: it
was selected from the proMMP-2 Glu\textsuperscript{62}--Leu\textsuperscript{63} autolytic
site for its biosensor-compatible sequence properties (charge distribution, methylene
blue conjugation geometry) rather than for being a natural collagen/fibronectin cleavage
site. The PSSM trained on natural MMP14 ECM substrates does not place SGRSENIR among
its top-3 amino acids at every position, so it falls outside the $3^8$ enumerated
candidate set entirely.

Second, the FAP classifier assigns \texttt{SGRSENIR} a high probability (0.685), which
suppresses selectivity. This is an artefact of the degenerate FAP model (Section~\ref{sec:fap})
and should not be interpreted as evidence that FAP cleaves SGRSENIR in vivo.

The ML-preferred top candidate, \texttt{DVANYVEH} ($p = 0.976$, $S = 2.26$), encodes
Tyr at P1 and Glu at P2': both are characteristic of MMP14 hydrophobic pocket specificity
in ECM remodelling substrates. Whether this motif retains the electrochemical signal-off
properties required for the biosensor is an open experimental question.

\begin{tcolorbox}[colback=gray!7, colframe=gray!40, boxrule=0.4pt,
  arc=2pt, left=6pt, right=6pt, top=4pt, bottom=4pt]
  \textbf{Interpretation.} The ML tool correctly identifies that SGRSENIR is not a
  natural MMP14 substrate by the MEROPS-derived PSSM criterion. This does not
  invalidate the existing sensor design: SGRSENIR has a validated
  $k_\text{cat}/K_M = 5.5 \times 10^4\ \text{M}^{-1}\text{s}^{-1}$ and the Task~2
  Hill-equation model confirms clinical feasibility at the 0.1\% SWV noise floor.
  However, if wet-lab synthesis yields confirm that an ML-predicted candidate such as
  \texttt{DVANYVEH} achieves a higher $k_\text{cat}/K_M$, the Task~2 LOD would improve
  proportionally and the 30-min assay window could be shortened. Any adopted candidate
  must have its $k_\text{cat}/K_M$ measured to re-run the Task~2 kinetic model before
  committing to electrode fabrication. The predicted NE substrate \texttt{PETISLPP}
  (selectivity 17.9) is the highest-confidence recommendation from this analysis.
\end{tcolorbox}

\subsection{FAP Confidence Caveat}\label{sec:fap}

FAP (fibroblast activation protein; MEROPS S09.007) has only 2 confirmed cleavage windows
in the MEROPS bulk substrate file. The trained FAP classifier is therefore degenerate: its
predicted probabilities reflect the VHSE8 features of two specific sequences and have no
generalisable meaning. FAP is excluded from all selectivity comparisons except as a formal
competitor probability term. The high-selectivity FAP candidates in Table~\ref{tab:top_candidates}
are artefacts. A reliable FAP model would require at minimum 50 confirmed cleavage windows,
likely obtainable only from a purpose-built substrate library or an expanded FAP-specific
biochemical screen.
